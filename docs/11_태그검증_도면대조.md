### 1-1. 하마터면 잘못 정정할 뻔한 것 — 라인 문자 규칙

교육자료의 «설비 식별번호 부여기준» 표를 OCR 로 읽고 `Y = 발전소 COMMON` 이니
`TI21Y` 가 Z 계열이라고 판단할 뻔했다. **이미지를 직접 보니 지역마다 규칙이 다르다**:

| 설치지역 | 번호 | 라인별 일련번호 규칙 |
|---|---|---|
| 주배관 | 1 | 순차 `A~Z` |
| **필터** | **2** | 순차 `A~Z` / **COMMON(BY-PASS 포함) `Y, Z`** |
| 히터 | 3 | 도시가스 `A~M`, 도시가스 COMMON `L,M` / 발전소 `O~Z`, 발전소 COMMON `Y,Z` |
| 정압기 | 4 | 히터와 동일 |

`TI-21Y` 는 **필터지역** 태그라 `Y` 는 단순히 "COMMON 라인"이고 발전소 의미가 없다.
어느 COMMON 이 어느 계열인지는 **문자가 아니라 도면으로만** 정해진다.

⚠ OCR 만 믿고 정정했으면 계열 배정을 통째로 뒤집는 오류가 났다. **표는 이미지를 직접 볼 것.**

### 1-2. 헤더 태그가 정말 연속 온도인가

`TSL/TSH/TSHH` 는 **스위치** 약어다(교육자료: TS→TEMPERATURE SWITCH). 스위치 상태가 아니라
온도값인지 데이터로 확인했다 — 다른 온도 태그와 동일한 성질이다:

| 태그 | n | 고유값 | 최소 비영변화 |
|---|---|---|---|
| `TSL_TSH_TSHH-31M` | 6,408,820 | 948 | 0.0610 ℃ |
| `TSL_TSH_TSHH-31Z` | 6,419,023 | 950 | 0.0610 ℃ |
| `TI33A` (대조) | 7,371,091 | 1,194 | 0.0610 ℃ |

P&ID 상 하나의 `TE-31M` 이 3개 스위치와 지시계를 공유한다. **TE 의 아날로그 값이 맞다. ✓**

## 2. 🔴 새로 발견 — 모형을 무효화하는 것

### 2-1. 계열 간 교차연결 `350-NG-P7-319` 이 있다

```
M 합류헤더(309) ──── 319 ──[V-31M]── Z 합류헤더(358)
```

- P&ID(4) 에서 `319` 는 합류헤더 `309` 상단에서 분기해 P&ID(1) 로 간다(`V-31M` 경유).
- P&ID(1) 에서 `319` 는 `400-NG-P7-358`(Z 합류헤더) 바로 옆에 붙는다.
- **양쪽 모두 헤더 온도계 상류**에 연결된다 — Z 측 `TE-31Z` 탭보다 왼쪽(상류).

**두 계열이 독립이라는 전제가 깨진다.** 그리고 `V31M` 은 KPOS 태그로 존재하지만
**DI 데이터가 0건**이다 — 수동밸브이고 개폐 상태를 알 수 없다.

데이터로 본 증거 — 각 헤더를 **자기 계열 변수만으로** 회귀한 잔차(공통 시각 1,769,165행):

| | R² | 잔차 σ |
|---|---|---|
| M 헤더 | 0.505 | 5.03 ℃ |
| Z 헤더 | 0.386 | 4.03 ℃ |

```
Spearman(잔차_M, 잔차_Z) = +0.351      대조군(치환) +0.002
시차:  −60분 +0.322 | −15분 +0.343 | 0분 +0.350 | +15분 +0.344 | +60분 +0.319
```

**lag 0 에서 최대이고 대칭으로 감소한다.** 모형 밖 공통 구동원이 있다는 뜻이고
교차연결과 일치한다. 다만 대기온도·상류 공급조건 같은 **공통 외생변수로도** 같은 모양이
나오므로 이것만으로 교차유동이 있었다고 단정할 수는 없다.

### 2-2. 각 히터 출구는 `TI-33x` **직후 지중 매설**된다

P&ID 상 순서:

```
HTR-31A → 300x400 → [TE/TI-33A] → V-32A → PV-33A → V-33A
        → ABOVE GROUND│UNDER GROUND → 합류헤더 309 (매설) → 310 → [TE-31M]
```

**합류점이 매설 구간 뒤에 있다.** 즉 `(Q4)` 에 `TI-33x` 를 그대로 넣은 것은 **틀린 지점의
온도**다. 각 가지마다

    T_합류,u = T_지중 + (T_33,u − T_지중)·exp(−N_u),   N_u = U·A_매설/(m_u·c_p)

가 먼저 적용돼야 한다. 저유량 가지일수록 `N_u` 가 커서 지중온도로 무너진다.
배관 구간에 대해 이미 `(Q6)` 로 확인한 바로 그 구조다(문서 09).

### 2-3. 버너는 ON/OFF 가 아니라 **변조 제어**다

교육자료(3. 가스히터, BURNING LINE ACCESSARY):

> "열매체액 GH-110의 온도에 따라 **BLOWER MOTOR의 회전수를 조절**하여 MAIN BURNER 부하제어"

`burner_u` DI 는 화염 유무일 뿐이고 **화력률이 아니다.** `duty × Q_설계` 로 발열을 계산한
`(Q1)` 은 구조적으로 틀렸다 — 문서 09 §4 의 "버너 발열이 ε 역산 흡수열의 1/3~1/4" 격차의
유력한 원인이다. 블로워 회전수(인버터) 신호가 데이터에 있는지 확인해야 한다.

### 2-4. 열매체는 물이 아니라 **GH-110**

태그명은 `BATH WATER TEMPERATURE` 지만 교육자료는 일관되게 **열매체액 GH-110** 이라 쓴다.
`C_eff` 는 실측으로 식별했으므로 기존 결과는 영향이 없지만, 물성값(비열·점도)을 물로
가정한 계산이 있다면 전부 재검토 대상이다.

## 3. 부수 확인

- **KOGAS 공식 줄-톰슨 계수**: "0.1 MPa 감압 시 온도 **0.56 ℃** 강하" → **0.56 ℃/bar**.
  7 MPa → 0.85 MPa 에서 약 35℃ 강하라는 예시와 정합(61.5 bar × 0.56 = 34.4℃).
  PINN 학습값은 M 0.443 / Z 0.427 로 **공식값보다 낮다**(허용범위 상한 0.60).
- **계기 신호 경로**: `TT-31A`(현장 전송기) → `TY-31A`(제어실 변환기) → `TI-31A`(K-POS 화면)
  → OVISION(지역통제소) → `XR-61M`(기록계). K-POS 값은 **현장 전송기의 3단계 하류**다.
- ⚠ `251016 설비이해자료.pptx` 는 **영종이 아니라 영암GS** 자료다("영암GS 공급계통",
  목포 C/G·서호 B/V). 설비 일반론에는 쓸 수 있으나 **영종 고유 구성의 근거로 쓰면 안 된다.**
