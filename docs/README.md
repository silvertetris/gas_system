## 한 장 요약 (2026-09-12 기준)

**목표** — 영종 G/S 가스히터의 열화지표 `φ = U·A / U·A_clean` 를 추정하고 고장을 예측한다.
대상은 **HTR-31A · 31B · 31O · 31P 4대**(31C 는 미설치, 계획설비).

**확정된 것**
- 설비는 **두 계열**로 완전히 분리돼 있다: **M**(A+B, 도시가스, 0.8 MPa) / **Z**(O+P, 공항·발전, 2.6 MPa).
- 각 계열에는 **히터를 건너뛰는 냉가스 바이패스**가 있고, 온도조절기가 그 양을 조절해
  출구 공통헤더 온도를 맞춘다. **가스의 41%(M)·60%(Z)는 히터를 지나지 않는다.**
- 히터 출구온도는 자유변수가 아니라 **피제어 변수**다. 열화가 생기면 컨트롤러가 바이패스를 조여
  헤더온도를 지킨다 → **열화 신호는 출구온도가 아니라 바이패스 분율 `β` 와 `U·A` 에 남는다.**
- 운전상태 레이어(`flow` / `lowflow` / `isolated`)를 만들어 검증했다. 열전달 해석이 유효한
  `flow` 구간이 히터당 **692~2,000일** 있다.

**🔴 확정된 제약 (§07)**
- **유량 절대값은 8개 경로 전부 막혔다.** 유량계 NULL · 밸브 개폐신호 · 차압 분해능 · ε 미식별 ·
  버너 `fire` 미식별 · 수조 냉각 잡음 · β 는 ε 과 동일정보 · 배관냉각은 줄-톰슨 지배.
- **정비가 어떤 관측량에도 흔적을 남기지 않는다.** 지표 6 × 히터 4 = **24개 검정에서 유의 0개**
  (대조군 대비 단측 순위검정, 최소 p=0.465).
- → **열화(②)·RUL(③) 은 이 데이터로 불가능하다.** ① Hard fault 도 알람이 고장이 아니라 기각.

**✅ 성립한 것 (§08)** — **6시간 빙결 위험도**. 히터의 설계 목적(줄-톰슨 냉각 상쇄)이 실패할 확률.
고장 라벨·유량·`U·A` 가 전부 필요 없고, 캘리브레이션으로 검증된다.
AUC 0.79~0.84, Brier 기준선 대비 +44~56%, 상위 1% 리프트 **17~24배**.
Z계열은 임계 0.5 에서 **연 9시간 경보에 정밀도 71.8%**.

**아직 없는 것** — 진짜 고장 라벨. SCADA 에 "고장났다" 는 신호가 없다(05 문서 참고).
