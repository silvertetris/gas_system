### 1-3. ⚠️ 함정이 있는 태그

- **`ZI41A`/`B`/`C` 는 0~100% 가 아니다.** 최대 3,000, 중앙 174~266. `ZI41O/P/Q` 만 0~100.
- **`ZI41O`/`P`/`Q` 는 중앙 99.6~100 · p10 0.00** — 변조 위치가 아니라 사실상 **개폐 신호**.
  밸브식 유량 역산 불가.
- **`RS41x` 는 `RSF41x` 의 스팬 백분율**이라 중복 정보
  (`RSF41A` 0.84 / 스팬 1.5 = 56 ≈ `RS41A` 55.87).
- **`PDI21x`(필터 차압)는 분해능 0.05 · 중앙 0.00** — 막힘 지표로도 유량 지표로도 못 쓴다.
- **`TI-D2x` 분해능 0.061℃.** 인접 차분은 대부분 0 아니면 ±1양자 → **`dT/dt` 를 단순 차분으로 구하면
  계단이 된다.** 반드시 구간 내부 최소제곱 회귀로 기울기를 뽑을 것.

## 2. 🔴 DI(상태/알람) 로그의 3가지 함정

`H31POH`(P호기 버너 점화상태) 기준 실측. **4대 전부, 모든 DI 태그가 같은 성질**이다.
원본 CSV 를 그대로 읽으면 **반드시 틀린다.**

| # | 함정 | 실측 | 대응 |
|---|---|---|---|
| 1 | **행 중복 93%** | 시각 있는 이벤트 1,112,185건 → `(Time,값)` 중복 제거 시 **78,791건**. 제거 전에는 "연속 이벤트의 값이 바뀌는 비율"이 0.084 로 나와 상태 로그로 보이지도 않는다(제거 후 0.941) | `drop_duplicates(["Time","v"])` |
| 2 | **시각 없음 47.5%** | `Time` 이 `2011-10-06 n/a` 형태로 **날짜만** 있는 행 1,006,642건. `to_datetime(errors="coerce")` 가 NaT 로 만들어 **조용히 사라진다**. 이벤트가 있는 4,781일 중 **435일(9.1%)은 시각 있는 이벤트가 하나도 없다** | 버리되 **미상은 NaN 으로 남긴다** |
| 3 | **값 비트팩 6%** | `4294967041`, `87565569` 같은 값이 섞임. **하위 1비트가 실제 상태** (`4294967041 & 1 = 1`) | `v & 1` |

**검증**: 이렇게 복원한 상태로 수조온도 변화율을 보면
**ON 중앙 +0.488 ℃/h, OFF 중앙 −0.976 ℃/h, OFF 구간의 90.8% 가 실제 냉각**. 방향이 맞는다.
(반대로 ON 구간은 51.8%만 승온 — ON→OFF 전이 누락으로 ON 이 부풀려져 있다.)

> ⚠ **이 보정은 전처리(`prex_multi/trend.py::add_burner_state`)에 한 번만 있다.**
> 분석 모듈에서 다시 구현하지 말 것. `burner_A/B/O/P` 컬럼을 쓴다.

복원 결과: 상태변화 A 60,090 · B 60,349 · O 34,701 · P 74,156 건,
ON 비율 14.0~19.2%, 미상 0.04~0.13%.

`MOV31A/B/C/O/P`(히터 차단밸브)도 같은 처리를 하면 쓸 수 있으나
**유효 상태변화가 15년간 연 20건 수준**(269~307건)이고 DI_01 은 2026-04-09 에서 끝난다.
정비 시 격리 기록이지 상시 운전 신호가 아니다 → **분 단위 게이트로 못 쓴다.**
