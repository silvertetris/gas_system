### 2-1. 경로 4 정정 — "곱으로만 나타난다"는 틀렸다

구 판은 `NTU = U·A/(m·c_p)` 에서 `U·A` 와 `m` 이 곱으로만 나타나 미식별이라고 적었다.
**틀렸다.** `U` 는 `m` 과 독립이 아니다 — 제작도서 직렬저항 모델(문서 04 §H4, 부하표 대조 −0.1%):

```
1/U(x) = 1/(α_io·x^0.8) + 1/α_o + R_f              x = m/m_d
1/NTU  ∝ x^0.2/α_io + x/α_o + x·R_f                ← x 의 멱이 달라 곱으로 축약되지 않는다
```

`NTU(x)` 는 치역 0.026~3.13 **전구간 단조감소**라 유일하게 역산된다. 실제로 돌렸다
(690만행, 2013-06~2026-08): A x중앙 0.61 · B 0.24 · O 0.12 · P 1.09.

**그런데 독립 검증에서 떨어진다.**

| 검증 | 기대 | 결과 |
|---|---|---|
| 합류점 혼합 β vs 밸브개도 Spearman | 유량가중 > `max()` 근사 | M 0.827 vs **0.866** / Z 0.836 vs **0.840** — 개선 없음 |
| 계절성 겨울/여름 (M=인천도시가스) | **> 1** (겨울 피크 확실) | 중앙비 **0.86**, 평균비 0.74 |
| Spearman(m_total, T_in) | **음수** (추우면 수요↑) | M **+0.052** / Z **+0.151** |

**방향이 틀렸다.** 즉 `α_io`·`α_o`·`A`·`R_f`·`c_p` 를 제작도서 값으로 **고정한 순방향
역산**이 안 되는 것이고, 식 자체가 못 쓰는 게 아니다. 이 구분이 중요하다:

- 미식별이면 → 넣을 방법이 없다
- 검증 실패면 → **PINN 으로 그 상수들을 교정**하면 된다 (연립하면 식별된다)

```
(Q4) T_hdr = (1−β)·Σ(m_u·T_out,u)/Σm_u + β·T_in     ← T_hdr 실측 ⇒ 유량 **배분**을 묶는다
(Q1) C_eff·dT_bath/dt = s·Q_burner − m_u·c_p·ΔT_u − Q_loss   ← C_eff 는 열량계로 확보
                                                               ⇒ 절대 **스케일**을 묶는다
```

§2 의 8경로는 **직접 계측** 경로다. 연립 추정은 별개 문제이며 `pinn/` 에서 다룬다.

| 항목 | 내용 | 왜 |

| 대상 | `regime == "flow"` 구간만 | 열교환이 실제로 일어나는 곳 |

> 🐛 1차 실행에서 `duty`(버너 가동률)가 **조용히 빠졌다** — 0/1 계열이라 중앙값이 0 이 되어
> 비율 변화 가드에 걸렸는데 로그에 안 남았다. 이진 컬럼은 평균을 쓰도록 고쳐 재실행했고
> 위 표는 24개 전부 포함한 결과다.

### 왜 안 보이나 — 설명 셋

1. **제어루프가 흡수한다.** 바이패스 밸브가 히터 상태와 무관하게 헤더온도를 설정값에 맞추므로
   하류가 전부 평평해진다(§01 2-4). 다만 그렇다면 `β` 에는 남아야 하는데 β 도 p=0.55~0.78 이다.
2. **애초에 회복할 열화가 없다.** 정기점검은 **전부 예방정비**다(§05) — 막혀서 뚫은 게 아니라
   주기적으로 닦은 것이다. 제거할 오염이 적으면 회복도 없다.
3. **부하 변동이 압도한다.** 대조군 \|변화\| 중앙이 `duty` 에서 38~115%, `ntu` 에서 14~34% 다.
   히터가 설계의 13~100% 로 흔들리는데 열화 신호는 그보다 작다.

## 4. 이것이 ML 에 주는 함의

**같은 데이터로 신경망을 돌려도 학습할 열화 신호가 없을 가능성이 높다.**
물리 지표가 정비조차 못 보는데 잠재 표현이 그걸 볼 이유가 없다.

앞서 돌린 LSTM 파일럿이 persistence 대비 RMSE 를 20.4% 개선했지만
**고장 탐지 ROC-AUC 는 0.419** (무작위 0.5 보다 나쁨) 였다. 출구온도의 **자기상관**을 학습한 것이지
열화를 본 것이 아니다 — 이번 결과와 정확히 일관된다.

### 목표 재조정 제안

| 원래 목표 | 판정 | 대안 |

| ② Degradation | **근거 없음** (§3 에서 확정) | — |
| ③ RUL | ②에 의존 → 불가 | — |
