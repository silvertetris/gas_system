## A. 설비 구조를 잘못 읽은 것

### A-1. 🔴 바이패스를 통째로 빠뜨렸다 (가장 큰 것)

- **주장**: 가스가 입구헤더 → 히터 → 출구헤더로 **전량** 흐른다.
- **실제**: 히터와 나란히 **냉가스 바이패스**가 있고 온도조절기가 그 양을 조절한다.
  **가스의 41%(M)·60%(Z)가 히터를 지나지 않는다.**
- **어떻게 잡았나**: 태그 60개 중 6~10개만 쓰고 있다는 걸 깨닫고 전체를 훑다가
  `ZI31D`/`ZI31Q`(온도조절밸브 개도)를 발견 → 도면에서 그 밸브가 히터와 **다른 배관**
  (`250-NG-P7-308`, 보온 표기 `-H` 없음)에 있음을 확인 → 열수지로 계산한 β 와 밸브개도가
  Spearman +0.87/+0.84 로 일치.
- **파급**: §11~§13 의 `m_gas`·`Q_loss`·`φ` 수치 **전부 폐기**. `gas_flow_proxy` 폐기.
- **교훈**: **가진 태그를 전부 훑기 전에 모델을 세우지 말 것.** 6개로 시작해 15년치를 돌렸는데
  구조를 규정하는 태그가 안 쓴 46개 안에 있었다.

### A-2. 히터 수를 2대 → 3대 → 2대로 두 번 뒤집었다

- **주장 1**: 계열 M 은 히터 2대(A, B).
- **주장 2 (오정정)**: 도면에 `31C` 가 있으니 **3대**다. 내가 `ZLH`+옆 행 `-31B` 를 잘못 붙여
  만든 가짜 라벨을 믿고 "3대인데 2대로 봤다"고 정정했다.
- **실제**: `31C` 버블은 **`INST-FU`(FUTURE) 레이어** — 미설치 계획설비다. **2대가 맞다.**
  배관(`304-H`/`307-H`)만 실레이어로 선시공돼 있다.
- **어떻게 잡았나**: DXF 의 `l`(레이어) 필드를 확인. 도면 006 주기에
  "(1) : FUTURE ITEMS & LINES" 가 명시돼 있다. 겹쳐 보이던 `INST` 레이어 문자열은
  블록 복사 시 갱신 안 된 **ATTRIB 정의 텍스트**였다.
- **교훈**: **P&ID DXF 는 레이어로 먼저 거른다.** 실설비와 계획설비가 같은 좌표에 겹쳐 있고
  ATTRIB 잔여 텍스트까지 섞인다. 문자 군집화 y 허용오차는 0.6 이하.

### A-3. `TI21Y`/`TI21Z` 를 이중화로 봤다

- **주장**: 같은 지점의 이중 계측이니 평균을 쓰자.
- **실제**: **서로 다른 계열의 필터 출구 헤더**다. `TI21Y`=A/B 계열, `TI21Z`=O/P 계열.
- **파급**: `prex` 가 도시가스 계열 온도를 P호기 입구로 섞어 쓰고 있었다.
- **교훈**: 상관 0.87 을 "불완전 이중화"로 해석했는데, 실제로는 **같은 외기를 따라가는 서로 다른 배관**
  이었다. 높은 상관이 동일 지점을 뜻하지 않는다.

### A-4. `PI43O` 를 O/P/Q 공용 헤더값으로 봤다

- **실제**: `PCV-41O/42O` **유닛 전용 출구배관**(`360-NG-P7-456`)의 값. P 전용이 아니다.

## B. 데이터를 잘못 읽은 것

### B-1. DI 로그를 원본 그대로 읽었다

행 중복 93%, 시각 없음 47.5%, 값 비트팩 6% — 셋 다 몰랐다.
자세한 것은 [02_데이터현황.md](02_데이터현황.md) 2절.
**교훈**: 이벤트 로그는 **상태 토글이 교번하는지** 먼저 확인한다. 교번율이 0.084 면 뭔가 틀린 것이다
(중복 제거 후 0.941).

### B-2. "10년간 진공 상실 = 고장" 이라고 주장했다

- **주장**: `PI-D2P` 가 깊은 진공을 잃은 구간이 곧 고장 상태.
- **실제**: 버너 ON 조건에서 비교하면 shallow 20.47℃ vs deep-1 20.25℃ 로 **사실상 동일**.
  운전 체제 차이지 고장이 아니다.
- **교훈**: 조건부로 비교하지 않고 전체 중앙값을 비교했다.

### B-3. "552일만 일했다" 고 주장했다

- **주장**: `H31POH` ON 시간을 합쳐 보니 120개월 중 552일.
- **실제**: `H31POH` 는 **버너 점화 사이클**(ON 중앙 15분)이지 "히터 가동 기간"이 아니다.
  승온폭 기준으로 다시 세면 **2,535일(49.4%)**.
- **교훈**: 사용자가 "1년에 6개월은 일하지 않나"라고 짚어서 발견했다.
  **상식과 어긋나는 수치가 나오면 그 태그의 정의부터 다시 본다.**

### B-4. "m_gas 는 시변이어야 한다" 고 주장했다

- **주장**: 구간별 추정치가 달라지니 `m_gas` 를 시변으로 둬야 한다.
- **실제**: 그 "비선형성"은 **양자화**였다. 구간 중앙값이 정확히 0.678e-4 K/s 의 1, 2, 3, 23배
  (= `TI-D2P` 분해능 0.061℃ 의 정수배)였다.
- **교훈**: 사용자가 "열전달 법칙인데 어디 사라지느냐"고 짚었다.
  **분해능의 정수배로 떨어지는 값은 물리가 아니라 계측 격자다.**

### B-5. "A/B/O 와 P 는 모델이 다르다" 고 주장했다

- **실제**: 버너 OFF 냉각 구간을 섞어 중앙값을 비교했다. 버너 ON 조건으로 맞추면
  P 가 TIC 60~80℃ 범위에 71% 들어온다. 같은 설계 체계다.

## C. 방법론을 틀린 것

### C-1. 🔴 열별 중앙값을 같은 행처럼 비교했다

"A 가 37.15℃, B 가 12.79℃ 인데 헤더가 23.57℃ — 모순" 이라고 썼는데, 세 숫자는
**각 열의 중앙값을 따로 뽑은 것**이라 같은 행이 아니다. 행 단위로 다시 하니 99.7%/97.0% 가 실현가능.
**교훈: 실현가능성 검사는 반드시 행 단위로.**

### C-2. 🔴 모델마다 다른 표본으로 R² 를 비교했다

증분 R² 비교에서 각 모델이 잔차를 **따로** 절사했다. 표본이 달라지면 R² 는 비교 불가다
— 실제로 값이 −2.195 ~ 0.943 을 널뛰었다. MAD 로 **한 번만** 걸러 공통 표본을 쓰도록 고쳤다.
**교훈: 모델 비교 전에 표본을 고정한다.**

### C-3. 검정력 없는 검정을 돌리고 결론을 냈다

(H1)×(H5) 교차검증에서 계열 M 의 `ΔH` 중앙이 **2.75℃** 인데 헤더 기저 오프셋이 **2.49℃** 였다.
신호가 오프셋에 묻힌 상태로 "(H5) 기각"을 낼 뻔했다.
**교훈: 판정 전에 신호/잡음 비를 먼저 본다.**

### C-4. 두 가설이 같은 미지수를 공유하는 줄 모르고 비교했다

`Q_gas = m_tot·c_p·ΔH`(H5) vs `m_tot·c_p·Δ`(바이패스 없음) — **둘 다 `m_tot` 를 포함**하는데
그걸 빼고 `ΔH` 나 `Δ` 하나만 넣었다. 두 모형 다 설정오류라 구조를 가르는 검정이 아니었다.
**교훈: 경쟁 가설을 세울 때 공통 미지수를 먼저 소거한다.**

### C-5. "식이 닫힌다" 고 성급히 선언했다

"미지수 `f₁`·`f₂`·`m_tot` 셋에 식도 셋" 이라고 썼는데, 그 식들 안에 **`U·A₁`·`U·A₂` 가 들어 있었다**
(= 구하려는 값). 시점별로는 미지수 5, 식 3 으로 **2개 부족**하다.
**교훈: 미지수를 셀 때 "이미 아는 값"과 "추정 대상"을 섞지 않는다.**

### C-6. 스케일러·수치 버그 3건

- AE 가 PCA 보다 175% 나빴다 → robust 스케일러가 `ZI41P_frac`(IQR 0.0037)을 σ 35 로 부풀려
  손실의 99.7% 를 차지. StandardScaler 로 교체.
- float32 누적오차로 `PI-D2P` 평균이 −554.8(실제 −620), σ 17.3→65.4. 스케일러 통계를 float64 로.
- KF 가 전부 NaN → `np.percentile` 이 NaN 전파. `np.nanpercentile` 로.
- KF 평가가 불공정 → 이종 신호의 원단위 RMSE 를 평균. 표준화 공간으로 변경.

## D. 접근 자체를 기각한 것

| 접근 | 왜 기각 |
|---|---|
| 정압기 밸브식 `m_gas` 역산 (`gas_flow_proxy`) | 히터↔정압기가 1:1 이 아니고 공통헤더로 섞인다. `PI43O` 도 옆 라인 값 |
| "긴 OFF 로 `Q_loss`, 짧은 OFF 로 `m_gas`" 분리 | 240분에도 잔열 11 kW 가 남아 전제가 깨진다. 수백 kW 가 `m_gas` 로 흡수됨 |
| 잔열을 `Q0·exp(−t/τ)` 로 두고 동시 추정 | R² 0.99 로 보이지만 **`Q0` 가 음수**(−1,254 kW). τ 가 격자 하한에 붙어 사실상 1/L 회귀 |
| **(H3) ε → 유량 역산** | 청정 `U·A` 로 `Σf≤1` 만족률 26%(M)/76%(Z). 비율 자유화해도 격자 끝으로 발산 |
| AE·KF 를 원시 센서에 바로 적용 | 원시 출구온도는 **제어되는 변수**라 열화 신호가 지워져 있다 |

### B-6. 태그사전 파서가 표 3종 중 1종만 읽었다

- **주장**: LIVE 태그 47개 중 9개가 "태그사전 미등재"다.
- **실제**: 전부 사전에 있었다. 사전에 헤더가 **세 종류**인데 9열만 받았다:
  `9열 |태그|설명|호기/라인|측정량|…|` · `8열 |태그|설명|측정량|…|`(§3~§5 가스필터·계량설비·주배관) ·
  `4열 |태그|표에는|실제|조치|`(§0 예외표).
  → §3~§5 표를 통째로 놓쳐 `PI21X`·`TI61M/Z`·`PI61M/Z`·`PDI21A/B/O/P` 가 떨어졌다.
- **파급**: 그 9개 안에 **빙결 예측의 타깃(`TI61M/Z`)과 주요 특징(`PI21X`)** 이 있었다.
  정체를 모르고 `p_in`·"계량설비 출구온도" 같은 부정확한 이름으로 다뤘다.
- **어떻게 잡았나**: 태그별 EDA 그림을 만들다 "미등재 9개"가 눈에 걸려 원문을 직접 grep 했다.
- **교훈**: **표 파싱은 열 위치가 아니라 헤더 이름으로 매핑한다.** 그리고 파싱 결과에
  "미등재"가 남으면 파서를 의심한다 — 원본에 없는 것이 아니라 내가 못 읽은 것이다.

### B-7. `TI61M/Z`·`PI21X` 의 정체를 모르고 썼다

- `TI61M` = **`C/G(IN-CHN) SUPPLY TEMP.`** (인천도시가스 공급온도),
  `TI61Z` = **`IN-CHN AIR. SUPPLY TEMP.`** (인천공항 공급온도) — **수요처 공급온도**다.
  "계량설비 출구온도"로 적었던 것을 정정(docs/08).
- `PI21X` = **`MAIN LINE INLET PRESS`**, 설비 **주배관(MOV-11x)**. 히터 입구압이 아니다.
  따라서 `dp = PI21X − PI61x` 는 **전 구간 강하**다.
- **교훈**: 태그를 특징으로 쓰기 전에 **IO LIST 설명을 먼저 읽는다.** 이름 규칙만 보고
  "61 = 계량설비니까 계량 출구"라고 추정했는데, 그 태그의 용도는 공급 지점 감시였다.

## (2026-09-13) 🔴 "NTU 는 U·A 와 m 이 곱으로만 나타나 미식별" — 틀렸다

**어디에 있었나**: 문서 07 §2 경로 4.

**무엇이 틀렸나**: `U` 가 `m` 과 독립이라고 암묵적으로 가정했다. 제작도서 직렬저항 모델에서
가스측 막계수만 `α_io ∝ m^0.8` 로 변하므로

    1/NTU ∝ x^0.2/α_io + x/α_o + x·R_f          (x = m/m_d)

가 되고 `x` 의 멱이 달라 **곱으로 축약되지 않는다.** `NTU(x)` 는 치역 0.026~3.13 전구간
단조감소라 유일하게 역산된다.

**왜 놓쳤나**: 같은 저장소 안에 직렬저항 모델이 이미 문서 04 §H4 로 정리돼 있었는데
(구 형태 `U·A = UA_ref·(m/m_d)^0.8` 을 폐기하면서 만든 것), 식별성 판단에는 반영하지 않았다.
**한 문서에서 고친 식이 다른 문서의 결론에 반영됐는지 확인해야 한다.**

**정정 후 결론은 무엇인가**: 구조적 미식별이 **아니라** 순방향 역산의 **검증 실패**다.
제작도서 상수를 고정한 역산은 계절성 방향이 반대로 나온다(M 겨울/여름 0.86, 기대 >1).
그래서 PINN 에서 `U·A` 보정계수를 학습 모수로 두고 (Q4)·실측 β 로 묶는다 → 문서 09.

**남은 것**: `prex_multi/config.py:regime_thresholds` 가 아직 상수U 가정을 쓴다.
저유량에서 1.5배 어긋난다(x=0.25 에서 NTU 1.075 vs 1.622). 정정하면 문서 03 T1~T4 재검증 필요.
