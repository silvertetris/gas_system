# 05. 정비 이력과 고장 라벨

---

## 1. 🔴 진짜 고장 라벨은 없다

프로젝트 전체를 규정하는 제약이다.

- **SCADA 에 "고장났다"는 신호가 없다.** DI 의 `GAD1x`(수조 종합이상)·`BAB1x`(화염검출)·
  `GAB1x`(버너 트러블)은 **알람**이지 고장 판정이 아니다. 대부분 자동 복구되는 transient 다.
- `TAHD1P`(수조 수온 High)는 **신뢰할 수 없다** — 수조 5.9℃ 에서 발화한 기록이 있다.
- **정기점검 보고서에도 "무엇이 고장나서 교체했다"는 기록이 없다.** 전부 예방정비
  (세척·개선·소모품 교체)이고, 연 1회 스냅샷이라 1분 시계열과 정렬도 안 된다.

→ 지도학습용 라벨을 만들 수 없다. **열화지표 `φ` 를 추정하고 그 추세로 판정하는 방식**이
유일하게 가능한 접근이며, 검증은 **정비 시점에서 φ 가 회복하는지**로 한다.

## 2. 정비 시점은 데이터만으로 확정된다 (OCR 불필요)

규칙: **수조 `TI-D2P` < 1℃ 또는 진공 `PI-D2P` < −750 이 24시간 이상 연속.**
전 구간 적용 결과 9건이 잡혔고, 그중 7건이 정기점검 기록 연도와 정확히 대응한다.

| 탐지 구간 | 길이 | 대응 |
|---|---|---|
| 2011-10-06 ~ 10-12 | 141.5h | 2011 정기점검 |
| 2013-03-19 ~ 03-28 | 150.7 + 65.4h | 2013 정기점검 |
| 2015-03-09 ~ 03-16 | 172.1h | 2015 정기점검 (OCR 로 3/16~17 확인) |
| 2017-03-24 ~ 03-31 | 171.9h | 2017 정기점검 |
| 2019-03-18 ~ 03-21 | 73.0h | 2019 정기점검 |
| **2021-03-29 ~ 04-02** | **99.5h** | **2021 정기점검 — 보고서와 분 단위 일치** |
| 2022-10-17 ~ 10-21 | 95.4h | ⚠ 정기점검 기록 없음 — 비정기 작업? **미확인** |
| **2024-10-17 ~ 10-29** | **294.1h** | **2024 정기점검 — 보고서와 분 단위 일치** |

- 이 일치가 **탐지기의 신뢰 근거**다. 나머지 연도(2013·2015·2017·2019) 스캔 PDF 는
  "무엇을 했는지"가 필요할 때만 열면 된다.
- 주기가 **2011~2021 은 2년(3월)**, **2024 는 10월**로 바뀌었고 2021→2024 는 3.5년 간격에
  작업 규모도 훨씬 컸다.
- 4대 히터 각각에도 같은 탐지를 적용할 수 있다(수조온도 <10℃ 24h 기준).

### 2-1. 무엇을 했나 (OCR 완료분)

| 정기점검 | 주요 작업 |
|---|---|
| **2024.10.17~10.30** | Fire & Smoke Tube **취외·고압세척·개선**, Vessel 고압세척 |
| **2021.03.29~04.02** | 같은 형식의 예방정비 |

Fire/Smoke Tube 세척은 **`U·A` 를 회복시키는 작업**이다 → φ 톱니의 물리적 근거.

## 3. 고장 경향성 분석 보고서 — 도메인 prior

`data/24~25 공급설비 고장 경향성분석 결과/` 4건 중 **2025 하반기 PDF 만 가스히터를 다룬다**
(상반기는 핵심설비가 정압·계량설비라 히터가 대상 외). 텍스트 PDF 라 `pypdf` 로 바로 읽힌다
(2024년 2건은 `.hwp`).

**전국 집계에서 가스히터가 단일 설비 1위** — 2025년 646건 중 **106건(16.4%)**.

| 분야 | 건수 | 주요 현상 | 주요 원인 | 주요 조치 |
|---|---|---|---|---|
| 기계 | 41 | 외부Leak 10(24%) · 내부Leak 6(14%) · **내용물 과/부족 4(10%)** | **노후/장기사용 21(51%)** | 교정 9 · 부품교체 7 · **충진/보충 7** |
| 계전 | 65 | 계기불량 14(21%) · **경보 12(18%)** | 부품불량 22(34%) · 노후 18(27%) | **부품교체 36(55%)** |

**모델링과 직결되는 사례 2건**
- **경기지사** — 열매체액 외부 누수 / 원인 **Tube Bundle 부식**(장기사용·수분·고온)으로 Hole 발생 /
  조치 부식부 용접 보강 → **튜브번들 부식 = `U·A` 저하의 실증된 경로.** 우리가 잡아야 할 열화 모드.
- **전북지사** — Blower Motor 소음 / 원인 Bearing 노후 → 연소 공기측 열화.

계전 개선대책의 "Ignitor 연소케이블 절연불량 주기적 교체"는 **화염검출 알람(`BAB1x`)의 원인 후보**다
— 불꽃이 실제로 꺼진 게 아니라 점화 회로 문제일 수 있다.

**⚠ 라벨로는 못 쓴다**: 전국 10개 지사 집계라 영종 데이터가 아니고(인천지사 사례는 정압기 1건),
반기 단위라 1분 시계열과 정렬 불가.

**⚠ 모델 가정을 하나 흔든다**: 기계고장 41건 중 **열매체액 충진/보충이 7건(17%)**.
`M_w·c_w` 를 제작도서 값으로 고정해 뒀는데 실제로는 누수·보충으로 변한다
→ 수조 유효 열용량을 잠재변수로 두는 근거.

## 4. 알람 SET POINT (남사·안중 참고도서)

| 구분 | 항목 | SET POINT |
|---|---|---|
| 알람 | 수조수온 H / L / **L-L** | 90 / 20 / **5 ℃** |
| | 수조수위 H / L | 950 / 150 mm |
| | 연료가스압 H | 300(안중) / 350(남사) kPa |
| | 가스감지 H | 5% LEL |
| 정지 인터록 | 가스감지 H-H | 10% LEL |
| | **스택온도 H-H** | **200 ℃** |
| | **수조수온 H-H** | **95 ℃** |
| | **화염검출 OFF** | **4 μA** |
| 제어 | **`TIC-D2` 수조온도 제어기** | **60~80 ℃** |
| | 연료가스 감압 PCV-A1/A2 | 250 / 300 kPa |

두 참고문서 간 차이는 **연료가스압 계열뿐**이고 온도·수위·화염 임계는 완전히 동일하다.
**물성·설계체계는 전용 가능하고, 설정값은 현장별**로 봐야 한다.
실측 검증: P 호기가 TIC 60~80℃ 범위에 **71%** 들어온다(버너 ON 조건).

⚠ P 는 참고문서(남사·안중)와 **설계 사양이 다르다** — 같은 계열로 묶지 말 것.
