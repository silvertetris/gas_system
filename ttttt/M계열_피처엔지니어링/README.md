# 계열 M 피처 엔지니어링 — 원형 12개에서 모델 입력까지

[원형 데이터](../M계열_원형데이터/README.md)의 원형 태그 12개를 빙결 예측 모델의 입력으로 바꾸는 과정을 정리한다.
**과거 값만 쓴다.** 모든 피처는 시각 t까지의 관측으로만 만든다. 미래 값은 타깃 `y_*`에만 들어간다.

- 기본 해상도는 1시간이다(`PINN_RES_MIN=60`). 피처 이름의 숫자는 행 수가 아니라 **시간**이다.
- 코드 위치
  - 기반 피처: `pinn/restricted/data.py` → `build_base("M")`
  - 정제 신호 붙이기: `pinn/restricted/data.py` → `add_refine()`
  - β·버너 상태: `prex_multi/trend.py` → `add_train_features()`, `add_burner_state()`
  - KF·AE: `risk/refine.py`
  - EKF: `pinn/restricted/ekf.py`
  - 표준화·결측 플래그: `pinn/restricted/train.py` → `prepare()`

## 한눈에 보기

| 단계 | 내용 | 피처 수 |
|---|---|---|
| 0 | 1분 → 1시간 집계 | 14 |
| 1 | 물리 파생 (ΔP, β, 유량) | +3 |
| 2 | 이력·계절 | +15 |
| — | **기반 피처 합계** | **32** |
| 3 | 정제 신호 (KF 7 · AE 2 · EKF 4) | +13 (조합 선택) |
| 4 | 표준화 + 결측 0 대치 + 결측 플래그 | + 플래그 |

정제 신호를 모두 넣으면 45개에 결측 플래그가 붙는다. 실제로 몇 개를 쓰는지는 Optuna가 고른 정제 조합에 따라 달라진다(§3 끝 참고).

## 1단계 — 물리 파생

### `dp` — 압력강하 [bar]

```
dp = (p_in − p61) × 10
```

줄-톰슨 강하 `μ_JT·ΔP`의 입력이다. 평소 약 50 bar이므로 약 25 ~ 28 ℃ 강하에 해당한다.

### `beta` — 바이패스 분율

합류점 열수지 `T_hdr = (1−β)·T_hot + β·T_in`을 β에 대해 푼다(c_p는 양변에서 소거된다).

```
β = (T_hot − T_hdr) / (T_hot − T_in),   T_hot = max(TI33A, TI33B)
```

- 1분 격자에서 계산한다.
- 다음 경우에는 결측으로 둔다.
  - `T_hot − T_in ≤ 10 ℃`: 분모가 작아 불안정하다.
  - 헤더온도가 유효하지 않다.
  - β가 [−0.15, 1.15] 밖이다.
- 두 히터가 동시에 다른 온도로 통가스 중이면 β가 살짝 과대평가된다. 한쪽만 통가스인 경우(대부분)에는 정확하다.
- 밸브 개도 `ZI31D`와 Spearman +0.92로 맞는다. 독립된 두 경로가 서로 일치한다는 뜻이다.

### `log_m`, `m_obs` — 계열 총유량

1. **히터별 유량**은 수조 열수지 사이클(`heatflow_cycles.parquet`)에서 얻는다. 버너 ON/OFF 동안 수조 온도가 변하는 속도로 가스 유량 m [kg/s]를 역산한 값이다.
2. 사이클이 없는 시각은 **과거 방향으로만** 최대 6시간 채운다.
3. A·B를 더한 뒤 바이패스로 간 몫을 보정한다.
   ```
   m_tot = (m_A + m_B) / (1 − min(β, 0.8))
   ```
   β → 0.95에서 106 kg/s가 나온 적이 있어서 β 상한을 0.8로 둔다.
4. 계열 총유량은 설계 총유량의 2배를 넘지 않게 자른다.
5. `log_m = log(max(m_tot, 0.05))`로 바꾼다. N = UA/(m·c_p)가 발산하지 않게 하한을 둔다.
6. `m_obs` = 열수지 유량이 실제로 관측된 시각이면 1. 물리 잔차는 이 시각에만 건다.

`m_tot`는 `log_m`과 겹치므로 입력에서 뺀다.

## 3단계 — 정제 신호 (KF · AE · EKF)

셋 다 **예측기가 아니라 정제 도구**다. 출력은 PINN의 입력으로만 쓴다. 평가도 "정제 신호를 넣으면 하류 모델이 좋아지는가"로 한다.

| 도구 | 보는 것 | 해상도 | 산출 |
|---|---|---|---|
| KF | 태그 하나의 선형 흐름 | 1분 → 1시간 집계 | 평활값, 혁신 |
| AE | 다변수 조합의 정상성 (모드별) | 1분 → 1시간 집계 | 재구성 오차 |
| EKF | 줄-톰슨 + 매설배관 물리와 관측의 정합 | 1시간 | 물리 일관 상태, 물리 이탈 혁신, 유량 추정 |

### 운전 모드

KF와 AE는 운전 모드를 기준으로 나눠 돌린다.

| 모드 | 정의 | M 비중 | 모드 안 빙결 발생률 |
|---|---|---|---|
| `run` | 통가스 중인 히터가 하나라도 있다 | 72.1% | 1.89% |
| `part` | 저유량이거나 일부만 통가스 | 27.2% | **10.46%** |
| `idle` | 전부 차단 | 0.8% | 3.39% |

`part`의 발생률이 `run`의 5.5배다. 모드를 섞으면 AE가 "어느 모드인가"를 재구성 오차로 내보내고 모드 안의 이탈을 보지 못한다.
**1분에서 해야 한다.** 1시간 집계로 모드를 판정하면 버너 사이클이 뭉개져 `idle` 비중이 0.8%에서 21.3%로 왜곡된다.

### KF — 7개

정상상태 국소수준 칼만필터다. 이득 K = 0.05로 고정되어 있어 EWMA와 같다(1분 격자에서 시정수 약 20분).

```
x_t = x_{t−1} + K·(y_t − x_{t−1})
혁신 = y_t − x_{t−1}   (관측 − 사전예측)
```

- 대상: `t61`, `hdr`, `t_in`
- 세그먼트가 끊기거나 운전 모드가 바뀌면 리셋한다.
- 적합할 모수가 없으므로 fold마다 다시 계산할 필요가 없다.

| 피처 | 의미 |
|---|---|
| `kf_t61`, `kf_hdr`, `kf_tin` | 평활값의 시간 평균 |
| `innov_t61`, `innov_hdr`, `innov_tin` | 혁신의 시간 평균 |
| `innov_t61_absmax` | 시간 안 \|혁신\| 최대. 1분 급락·계기 이상을 잡는다 |

### AE — 2개

- 입력은 원형 계측 12개를 표준화한 값이다: `TI-D2A/B`, `TI33A/B`, `burner_A/B`, 헤더온도, `TI21Y`, `TI61M`, `PI61M`, `PI21X`, 밸브 개도.
- `run`·`part` 모드마다 따로 학습한다(잠재 차원 5, 25 epoch). `idle`은 가스가 거의 흐르지 않아 뺀다.
- **적합 구간 끝(`fit_end`) 이전 데이터로만** 적합하고 전 구간에 적용한다. Optuna fold마다 경계에 맞춰 다시 적합한다.
- 히터 효율 `eps_u`는 넣지 않는다. 히터가 차단되면 NaN이 되어, 한 대만 차단돼도 행 전체가 빠지기 때문이다(1차 시도 커버리지 M 47%).

| 피처 | 의미 |
|---|---|
| `ae_err` | 재구성 오차의 시간 평균. 평소 안 나오는 센서값 조합 |
| `ae_err_max` | 시간 안 최대 |

### EKF — 4개

```
상태  x = [T_hdr, ΔP, T_in, log m]
전이  T_hdr·ΔP·T_in : 랜덤워크
      log m         : AR(1) → 학습평균
관측  z = [T_hdr, ΔP, T_in, log m (관측 시만), T_61]
      T_61 = T_g + (T_hdr − μ_JT·ΔP − T_g)·exp(−N)
      N    = U·A·e^{−log m}/c_p + N₀,   T_g = a + b·T_in
```

- 물리 모수(μ_JT, U·A, N₀, a, b)와 잡음 Q·R은 **학습 구간에서만** 따로 적합한다. PINN이 학습한 값은 쓰지 않는다(순환 방지).
- 필터는 전방향(인과)이다. 3시간 넘는 공백에서 리셋한다.
- **T_61 관측이 야코비안을 통해 log m을 끌어당긴다.** 그래서 열수지 유량이 비어 있는 시각(M 32%)에도 유량을 추정한다. KF·AE에는 없는 EKF만의 결과다.

| 피처 | 의미 |
|---|---|
| `ekf_logm` | 물리와 정합하는 유량 추정 (결측 시각 포함) |
| `ekf_logm_sd` | 그 불확실도 √P[log m] |
| `innov_ekf_t61` | `T_61 − f(x)` 사전 혁신. 물리식에서 벗어난 정도 |
| `nis_ekf_t61` | 혁신² / 혁신분산. 정규화한 이탈 |

### 어떤 조합을 썼나

정제 조합(없음 / KF / AE / EKF / 조합)은 Optuna가 다른 하이퍼파라미터와 함께 고른다.
기본 실행(hard PINN, `min_raw` 타깃)에서 계열 M은 **AE만** 선택됐다(`pinn/restricted/output/optuna/best_M.json`, CV AUC 0.779).
조합별 비교 결과는 `output/optuna/v_KF`, `v_AE`, `v_EKF`, `v_KF+AE+EKF`에 있다.

## 4단계 — 표준화와 결측

`train.py` → `prepare()`

1. 학습 마스크 구간의 평균·표준편차로만 표준화한다.
2. 결측은 0으로 채운다. 표준화 뒤이므로 학습 평균으로 채운 것과 같다.
3. 결측이 한 번이라도 있는 열마다 `결측_<열>` 플래그(0/1)를 붙인다.

LSTM은 같은 행렬을 과거 창 `[t−w+1, …, t]`로 잘라 쓴다. 창 안에 빠진 시각이 있으면 0 벡터를 넣고, 행 존재 마스크를 마지막 채널로 하나 더 붙인다.

## 타깃 — 미래 창 정렬

입력은 아니지만 피처 정의와 짝을 이루므로 같이 적는다.

1. 향후 6시간(t+1h ~ t+6h) 창에서 **`t61_min`이 가장 낮은 시각** t*를 찾는다. `mean` 타깃이면 `t61`을 기준으로 찾는다.
2. 그 시각의 상태를 모두 같은 t*에서 가져온다.

| 타깃 | 값 |
|---|---|
| `y_t61_min` | t*의 최저 공급온도 |
| `y_event` | `y_t61_min < 0 ℃`이면 1 (빙결) |
| `y_t61_mean` | t*의 1시간 평균 공급온도 |
| `y_hdr`, `y_dp`, `y_tin` | t*의 헤더온도·압력강하·입구온도 (상태 지도) |
| `y_log_m` | t*에 유량이 관측됐을 때만 |

상태마다 극값을 따로 잡으면 서로 다른 시점의 값이 한 물리식에 들어간다. 그래서 하나의 시각 t*에 모두 맞춘다.
창의 절반 이상이 관측되지 않으면 타깃을 결측으로 둔다.
